# TimerGame Web

Сайт для GitHub Pages. 4 минуты: случайная фотография 4–7 секунд, затем случайное аудио 3–5 секунд с обратным отсчётом. Каждая колода перемешивается без повторов до её исчерпания.

## Публикация

1. Создай **публичный** репозиторий на GitHub (например `timergame`).
2. Распакуй ZIP и загрузи **содержимое** архива в корень репозитория, сохранив `.github/workflows/pages.yml` (скрытая папка `.github` важна). Ветка должна называться `main`.
3. Добавь обычные фотографии в `photos/`, аудио в `audio/` через GitHub (Add file → Upload files). Поддерживаются JPG, PNG, WebP, GIF; MP3, WAV, OGG, M4A, AAC. Для лучшей совместимости используй JPG и MP3. В папках уже есть `.gitkeep`, чтобы они не исчезли из Git.
4. В репозитории открой **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Дождись успешного выполнения workflow **Publish TimerGame** во вкладке Actions. При каждой загрузке/удалении файлов через commit список `media.json` будет создаваться автоматически.
6. Открой `https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Важно

- Файл `media.json` в архиве пустой: он автоматически генерируется при публикации GitHub Actions. Если открыть `index.html` двойным кликом на компьютере, список медиа не загрузится. Используй GitHub Pages.
- Браузеры требуют нажатия кнопки для начала воспроизведения звука. Некоторые браузеры могут блокировать последующие аудиофайлы или приостанавливать страницу в фоне. Для наиболее надёжной работы держи вкладку открытой и экран включённым.
- Если аудиозапись короче интервала, она закончится раньше; следующая фаза всё равно начнётся по таймеру. Если длиннее — будет остановлена.
- Отсчёт четырёх минут использует реальное время. При переключении вкладок браузер может задержать визуальное обновление, но завершение определяется реальным временем.
- Для добавления медиа не нужно менять код. Не удаляй `.github/workflows/pages.yml`.
- GitHub Pages — публичный сайт. Не загружай личные или конфиденциальные файлы.
